# SurvScribe Mobile Application (`apps/mobile`)

Expo (React Native + TypeScript) application for iOS and Android.

## Architecture Highlights
- **Framework**: Expo SDK 57 (React Native 0.86). Continuous Native Generation (CNG) —
  the `ios/` and `android/` folders are generated by `expo prebuild` and are **not**
  committed.
- **Layout**: Feature-first structure (`src/features/<feature>/{api,components,hooks,screens,store,types}`)
  + `src/infrastructure/` + `src/shared/`.
- **Navigation**: React Navigation (bottom tabs) — `src/app/App.tsx`.
- **Database** (future): WatermelonDB over SQLite encrypted via SQLCipher (AES-256).
  This needs a **custom Expo development build** (an Expo config plugin, not Expo Go);
  it is wired up in the sprint that introduces the offline store.
- **Draft Engine** (future, post-MVP): client-side TypeScript `.docx` generator for
  offline preliminary and final survey report drafts.

## Environment
Copy `.env.example` to `.env`. Only variables prefixed `EXPO_PUBLIC_` are inlined into
the bundle. Never put a secret here — the bundle ships to devices. See `src/core/env.ts`.

## Development Setup
```bash
# Start the Expo dev server (choose a target from the CLI)
pnpm --filter @survscribe/mobile start

# Build + run on a connected Android device / emulator (runs expo prebuild first)
pnpm --filter @survscribe/mobile android

# Build + run on an iOS simulator (macOS only)
pnpm --filter @survscribe/mobile ios

# Regenerate the native projects explicitly
pnpm --filter @survscribe/mobile prebuild
```

From the repo root, `pnpm run dev:android` and `pnpm run dev:studio` wrap the Android
launcher script (`scripts/run-android.ps1`).
